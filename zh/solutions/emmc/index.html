    eMMC

    概况

    支持型号:

    BF6264B BF7264B BF7264B+ BF7264 Pro
    ● ● ● ●

    BF7264B/B+/Pro产品正面有两个USB孔

    eMMC 5.1方案，规格内容如下:

    • BF7264B/B+/Pro，32Gb RAM，搭配eMMC 5.1探头组

    • 支持 eMMC 5.1 Up to eMMC 5.1 HS400

    可显示eMMC协议封包数据以表格方式呈现，包含指令解析

    • 使用32Gb RAM搭配硬盘串流来储存eMMC通信数据，可完整节录待测物从低速初始化到高速传输数据的流程
    • 提供Data Filter功能，可将不必要的数据滤除以节省内存
    • 提供Search数据功能
    • 提供 CRC Packet 计算及错误显示
    • eMMC命令统计功能，包含封包总数、各类别指令数量以及错误数量统计

    • eMMC 命令触发功能
      • 触发参数包含命令与参数资料可依据不同种类封包填入数值,
      • 涵盖所有Command或16 byte Data,
      • 可触发CRC7, CRC16, End Bit Error,
      • 可触发3种timeout, CRC Status pattern,
      • 可触发VCC drop, VCCQ2 drop
      • 可透过Trigger-Out接孔同步触发外部的示波器

    • 报告区功能 ** 统计列表:** 以统计功能快速分类并可追踪数据位置

    • eMMC settings

    • Sample Rate: 选择使用的取样率, 若要开启Secondary Protocol Analyzer – NAND Flash选项, 取样率须设置为1GHz以下,
    • Primary Protocol Analyzer: 可选择使用探头类型, 也可自定义通道/触发准位,
    • Secondary Protocol Analyzer or I/O: 可额外开启一组指定之逻辑分析, 以剩下可用脚位同时进行分析
    • Startup Setting: 需设置于撷取当下, 待测物所运行之模式, 并有提供Tuning功能
    • Filter: 每一笔Data Frame可指定收录之大小, 大于设置值的数据则不会被记录下来
    • Trigger on: 可设置CMD, DATA, ERROR, Voltage, Timeout, CRC Status触发条件
    • 其他Option设置:
      • Vendor CMD: 可自行更改命令组名称, 是否带有数据
      • Timing: 设置symbols的clock数量。
      • 3 Pin mode: 接上CLK, CMD, D0后, 可进行命令流程以及状态的协议分析,
    • 主要用于接线困难或是非数据错误的待测物使用,
      • CLK Detect: 可侦测CLK是否有动作,
      • 两组电压侦测功能

    FAQ

    • 支持eMMC第几版的规格?
    • A: 支持到 eMMC 5.1 HS400 / HS200 / CMD Queue。
    • 量测时是否会影响信号质量?
    • A: 外接的仪器量测必然会有部分的负载效应影响，我们采用主动探头的连接方式来降低对待测物干扰并提升信号质量。

    • 是否有支持信号发送 (Tx) 功能? A: 不支持信号发送功能

    • 量测时须注意的事项 请确实按手册探头与待测物连接方式进行连接。

    • 有指定某个eMMC CMD 做为trigger点的功能吗?

    A: 可以指定特定的eMMC packet或是Error进行触发。

    • 是否可以自行设置一个eMMC CMD起始点，指定抓取多少时间内的Data?
    • A: 可以将起始条件设置在触发项目后，到工作模式选单内调整为数据监控仪模式，
    • 并指定撷取时间长度。

    • Secondary Protocol Analyzer or I/O

    • 在使用eMMC 5.1协议分析仪的同时, 可额外开启NAND Flash逻辑分析仪功能或是额外的I/O脚位进行分析。
    • 使用此功能必须在协议分析仪主画面将显示波形开启才能使用。

    • 由于NAND Flash的分析需要使用更多的通道, 因此需要一条LA探棒接于Slot A, 且仅能使用1GHz的采样率才能开启。

    主机与探头连接方式

    • 主机仅能使用Slot B作为探头连接槽。
