    Serial PSRAM (Serial Pseudo Static Random Access Memory)

    Serial PSRAM（串行 PSRAM）是 PSRAM（Pseudostatic RAM）的一种特别形式，使用串行接口与微处理器或其他系统通信。PSRAM 介于动态随机访问内存（DRAM）与静态随机访问内存（SRAM）之间：具有 DRAM 的高密度优点，操作相对接近 SRAM，并可简化内存控制。

    Bus Width／Latch Edge／DQS Delay 与器件不符时会解错。通道前缀差异见 Settings。

    Decode Settings

    • 总线宽度: 设置总线宽度为 8 或 16；选 16 时才栏位启用（Enable）较高位数据／DQS 通道。Default 为 8。
    • Latch Edge: 以 SDR 或 DDR 方式 latch 数据。Default 为 SDR。
    • DQS Delay: 设置 DQS 延迟（单位：采样点）。Default 为 0。
    • Latency: 细部设置各命令／数据延迟（打开参数文件编辑）。Default 按钮不重置此项。
