    详细与统计

    查看详细的协议数据，并分析流量统计。

    详细窗口

    查看数据量庞大的协议事务的完整细节。

    概览

    许多协议含有大量数值数据，不适合在主报告窗口显示。详细窗口提供这些数据的展开视图。

    打开详细视图

    方式：

    1. 在主报告窗口点击一行
    2. 特别点击 Data 列
    3. 完整数据显示于详细窗口

    显示内容：

    • 完整数据负载
    • 格式化显示（hex、十进制、ASCII 等）
    • 完整数据包结构
    • 正确格式化的多字节数据
    • 主报告未显示的溢出数据

    使用场景

    大量数据传输：

    • 256 字节以上的 I2C EEPROM 读取
    • SPI flash 页读取
    • UART 数据流
    • CAN 扩展帧

    复杂的协议结构：

    • 嵌套协议数据
    • 多层解码
    • 子协议细节
    • 负载解读

    数据验证：

    • 确认数据完整传输
    • 检查数据是否损坏
    • 验证 checksum 或 CRC
    • 与预期值比对

    统计窗口

    分析协议流量的样式与特性。

    概览

    统计提供整个采集范围内协议行为的高阶分析。不同协议按其特性提供不同的统计。

    访问统计

    方式：

    1. 点击 Window 菜单
    2. 选择 Statistics
    3. 统计窗口显示协议专属分析

    常见统计

    流量分析：

    • 事务总数
    • 每秒事务数
    • 读取与写入比例
    • 地址分布

    错误分析：

    • NACK 数量
    • Timeout 发生次数
    • CRC／checksum 错误
    • 协议违规

    时序统计：

    • 平均事务时间
    • 最大／最小时间
    • 空闲时间百分比
    • 总线利用率

    数据分析：

    • 数据率（字节／秒）
    • 平均负载大小
    • 数据分布样式
    • 协议命令频率

    使用统计

    找出问题

    高阶问题识别：

    • 异常的错误率
    • 性能瓶颈
    • 非预期的流量样式
    • 协议违规

    示例流程：

    1. 打开统计窗口
    2. 注意到某地址的 NACK 率偏高
    3. 用搜索找出 NACK 事务
    4. 为有问题的事务加书签
    5. 用详细窗口调查

    Trace 选择

    点击统计 trace：

    • 汇总所选 trace 类型的所有记录
    • 显示于统计列表窗口
    • 显示该事件类型的详细分项

    示例：

    • 点击“Address 0x50”统计 trace
    • 查看所有往返 0x50 地址的事务
    • 分析该特定设备的样式

    协议专属统计

    不同协议提供相关统计：

    I2C：

    • 地址使用分布
    • Clock stretching 发生次数
    • START/STOP 条件数量
    • 各地址的 ACK/NACK 比例

    SPI：

    • Chip select 触发次数
    • 数据传输大小
    • 时钟频率分布
    • CS 空闲时间

    UART：

    • 波特率准确度
    • 校验错误
    • 帧错误
    • Break 状况

    CAN：

    • Message ID 分布
    • 错误帧数量
    • 总线负载百分比
    • 重传统计

    Hide Data 窗口

    筛选显示，聚焦相关数据。

    概览

    用 Hide Data 功能暂时将数据项目移出视图，让您更容易聚焦特定协议活动。

    隐藏数据

    方式：

    1. 打开 Hide Data 窗口
    2. 选择要隐藏的数据项目
    3. 应用筛选
    4. 报告显示更新为只显示未隐藏的项目

    可隐藏的项目：

    • 特定地址
    • 事务类型
    • 错误状况
    • 特定协议（多协议采集中）

    还原数据

    方式：

    1. 打开 Hide Data 窗口
    2. 点击 Clear 按钮
    3. 所有隐藏的数据重新出现在报告中

    重要： Hide Data 只是显示筛选。隐藏的数据仍在采集中，随时可取消隐藏。

    使用场景

    聚焦分析：

    • 隐藏已知良好的流量以查看错误
    • 隐藏初始化序列以聚焦运行阶段
    • 隐藏大量地址以查看低流量问题
    • 隐藏特定命令类型以分析其他

    示例流程：

    1. 采集显示 0x50 地址有大量流量
    2. 隐藏 0x50 地址的事务
    3. 其他地址变得可见
    4. 不受干扰地分析低流量设备
    5. 清除隐藏筛选以重新查看完整样貌

    保存报告

    导出详细报告以做文档与进一步分析。

    保存为文本文件

    报告、详细与统计窗口的内容均可保存。

    支持格式：

    • .TXT — 纯文本格式
    • .CSV — 逗号分隔值（可导入 Excel／电子表格）

    保存选项

    1. 保存范围：
    2. 整个采集
    3. 仅选取的行

    4. 指定行范围

    5. 高级报告：

    6. 启用： 包含详细窗口的详细数据

    7. 停用： 仅主报告数据

    8. 时间戳选项：

    9. 合并： 时间戳与持续时间放在同一列

    10. 分开： 时间戳与持续时间分为两列

    11. 字节上限：

    12. 每列最大保存字节数
    13. 避免导出时列宽过大

    导出流程

    做文档：

    1. 分析采集，为关键事件加书签
    2. 隐藏无关数据
    3. 将可见数据导出为 CSV
    4. 在电子表格中打开并排版
    5. 加入测试报告或文档

    分享：

    1. 采集并分析数据
    2. 导出为 CSV 或 TXT
    3. 与团队成员分享文件
    4. 收件者可导入其工具进行分析

    提示与最佳实践

    详细窗口

    • 分析期间保持详细窗口打开
    • 用它验证主报告的解读
    • 将详细视图与预期的协议格式比对
    • 检查主报告是否有截断

    统计

    • 深入细节前先查阅统计
    • 用统计引导该仔细看哪里
    • 导出统计以做多次采集的趋势分析
    • 比较采集之间的统计以发现变化

    Hide Data

    • 大方使用隐藏数据 — 它不会破坏数据
    • 尝试不同的隐藏组合以观察样式
    • 最终导出前一律清除隐藏筛选
    • 在分析注释中记录隐藏了什么

    保存报告

    • 长时间分析期间定期导出
    • 用有意义的文件名保存（含日期、测试 ID）
    • 为求最大灵活性可考虑 CSV 格式
    • 文档中同时附上摘要报告与详细报告
