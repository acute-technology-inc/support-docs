    协议设置

    设置采集用的协议类型、通道与解码参数。

    协议配置样式

    按协议的复杂度，配置分为两种样式。

    样式 1：简易设置协议

    适用于配置简单的协议。

    配置步骤

    1. 选择协议： 从协议下拉列表选择
    2. 通道设置： 将设备通道分配给协议信号
    3. 波形预览： 软件自动检测信号波形与频率
    4. 选项： 设置该协议专属的采集与解码参数
    5. 阈值： 按信号规格设置电压电平

    使用样式 1 的协议：

    • 具自动信号检测的简单协议
    • 配置选项极少的协议
    • 自带时钟的协议

    样式 2：高级设置协议

    适用于需要较详细配置的协议。

    配置步骤

    1. 选择协议： 从协议下拉列表选择
    2. 设置采样率： 按协议速度指定采样频率
    3. 通道设置： 将设备通道分配给协议信号
    4. Trigger on： 为协议事件设置触发条件
    5. 选项： 设置该协议专属的采集与解码参数
    6. 阈值： 按信号规格设置电压电平

    使用样式 2 的协议：

    • 需要精确采样率的高速协议
    • 触发需求复杂的协议
    • 具多个时钟域的协议

    通道设置

    将物理通道分配给协议信号线。

    常见协议信号

    I2C：

    • SDA（Serial Data）
    • SCL（Serial Clock）

    SPI：

    • MOSI（Master Out Slave In）
    • MISO（Master In Slave Out）
    • SCK（Serial Clock）
    • CS（Chip Select）

    UART：

    • TX（发送）
    • RX（接收）

    CAN：

    • CAN_H（CAN High）
    • CAN_L（CAN Low）

    通道分配

    1. 从下拉列表选择协议信号
    2. 选择对应的设备通道
    3. 对所有必要信号重复
    4. 未使用的可选信号可不分配

    采样率设置

    设置符合协议速度的采样频率。

    准则

    最低采样率： 协议时钟频率的 4 倍

    建议采样率： 协议时钟频率的 10 倍

    示例：

    • I2C 400 kHz → 至少用 4 MHz（建议 10 MHz）
    • SPI 10 MHz → 至少用 40 MHz（建议 100 MHz）
    • UART 115200 baud → 至少用 460 kHz（建议 1.15 MHz）

    自动配置

    对于样式 1 协议，软件会按检测到的信号频率自动设置合适的采样率。

    波形预览

    样式 1 协议可用。

    功能：

    • 自动信号检测
    • 频率测量
    • 信号质量指示
    • 波形可视化

    显示内容：

    • 检测到的时钟频率
    • 信号电平
    • 边沿跳变
    • 信号完整性指标

    选项（协议专属设置）

    每个协议有专属的解码与采集选项。

    常见选项

    解码参数：

    • 地址格式（7-bit、10-bit 等）
    • 数据格式（hex、十进制、二进制、ASCII）
    • 字节序（big-endian、little-endian）
    • 错误检测（parity、CRC 等）

    采集参数：

    • 实时解码或采集后解码
    • 筛选设置
    • 数据包大小上限
    • 缓冲区设置

    显示选项：

    • 显示／隐藏特定数据包类型
    • 颜色标示
    • 报告格式偏好

    阈值设置

    设置判定逻辑电平的电压阈值。

    单一阈值

    设置一个阈值电压：

    • 信号高于阈值＝逻辑高（1）
    • 信号低于阈值＝逻辑低（0）

    建议： 将阈值设为信号电压电平的一半。

    示例：

    • 3.3V 逻辑 → 阈值：1.65V
    • 5V 逻辑 → 阈值：2.5V
    • 1.8V 逻辑 → 阈值：0.9V

    各通道阈值

    必要时不同通道可设置不同阈值。

    使用场景：

    • 混合电压系统
    • 电平转换后的信号
    • 同一总线上有不同逻辑家族

    快速预设

    常见阈值预设：

    • TTL（5V）：2.5V
    • CMOS 3.3V：1.65V
    • CMOS 2.5V：1.25V
    • CMOS 1.8V：0.9V
    • 自定义：手动输入

    触发设置

    样式 2 协议可用。

    触发选项

    按协议事件触发：

    • Start 条件
    • Stop 条件
    • 特定地址
    • 数据样式
    • 错误状况

    按信号事件触发：

    • 边沿跳变
    • 脉冲宽度
    • Timeout
    • 外部触发

    触发位置

    设置内存中前触发与后触发数据的百分比：

    • 0%：全部为后触发数据
    • 50%：前后触发相同
    • 100%：全部为前触发数据

    协议专属说明

    I2C

    • 地址格式：7-bit 或 10-bit
    • 速度模式：Standard（100 kHz）、Fast（400 kHz）、Fast-plus（1 MHz）、High-speed（3.4 MHz）
    • 注意 clock stretching

    SPI

    • 时钟极性（CPOL）：0 或 1
    • 时钟相位（CPHA）：0 或 1
    • 位顺序：MSB-first 或 LSB-first
    • 字大小：8、16、24 或 32 bits

    UART

    • 波特率：常见 300 至 921600
    • 数据位：5、6、7、8 或 9
    • 校验：None、odd、even、mark、space
    • 停止位：1、1.5 或 2

    CAN

    • 波特率：常见 125、250、500 kbps、1 Mbps
    • 帧格式：Standard（11-bit ID）或 Extended（29-bit ID）
    • CAN FD 支持：若有提供

    提示与最佳实践

    取得良好的采集结果

    1. 选择合适的采样率： 越高越好，但不要过高
    2. 设置准确的阈值： 用万用表测量实际信号电平
    3. 以已知良好的信号测试： 调试前先验证配置

    排查解码错误

    若解码失败或出现错误：

    • 检查通道分配
    • 确认阈值电平
    • 提高采样率
    • 用 Logic Analyzer 模式检查信号质量
    • 确认协议专属设置（波特率、时钟极性等）
