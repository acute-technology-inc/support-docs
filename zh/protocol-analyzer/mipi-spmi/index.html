    MIPI SPMI (MIPI System Power Management Interface)

    MIPI SPMI 协议分析设置。通道区域的产品差异请见 Settings。

    Supported Models

    LA3000/LA4000

    LA3000/LA4000 僅於 B 系列支援

    TravelLogic

    TL4000 僅於 B 系列支援

    BusFinder

    BF6000 僅於 B 系列支援, BF7000 全系列都支援

    Protocol Exerciser

    PX2816B 支援

    MSO2000/3000

    MSO2008E MSO2116E MSO2116B MSO2216B MSO2216B+ MSO2416B+
    ● ● ● ●
    MSO2216M+ MSO2116E+ MSO2116B+
    ● ●

    MSO3000 全系列都支援

    TravelScope 3000

    TS3000 全系列都支援

    Settings

    • 设定:
      • Bus Timeout: 总线逾时时间(滑杆；画面以时间显示)。逾时过短/过长可能影响封包边界判断。Default 约 96 µs。
      • Aribitration OFF: 关闭仲裁(arbitration)相关处理(画面标示用字)。Default 为未勾选。
      • Version: SPMI 规格版本(1.0/2.0)。设错会解码错位。Default 为 2.0。

    • 触发设定:

      • Trigger On — Error Trigger: 勾选要触发的错误类型。Default 为各项未勾选。
        • CMD Frame Format/CMD Parity: 指令讯框格式或同位错误。
        • Bus Park / Bus Handover: Park/交接异常。
        • Data Addr. Parity/Data Frame Parity: 资料位址或资料讯框同位错误。
        • Non ACK: 未收到 ACK。
        • Aribitration Format: 仲裁格式错误(画面标示用字)。
      • SPMI Packet: 依装置位址/指令/资料触发；勾选后齿轮栏位启用(Enable)，开启 MIPI SPMI Trigger Settings(见下方弹出窗口说明)。首次勾选通常会直接开启弹出窗口。Default 为未勾选。
        • Device Address/Command/Data Address: 要比对的装置位址、指令与资料位址；X/XX/XXXX h 表示任意值(Don't care)。
        • Data: 最多 16 字节之资料样式；其中 XXh 表示该字节为任意值(Don't care)。
        • Default: 还原弹出窗口为 don't care 条件。 在 SPMI Packet 旁按齿轮开启此窗口，依装置位址/指令/资料内容触发:

    • Device Address/Command/Data Address: 要比对的栏位；X/XX/XXXX h 表示任意值(Don't care)。

    • Data: 最多 16 字节之资料样式；其中 XXh 表示该字节为任意值(Don't care)。
    • Default: 还原为 don't care 条件。
