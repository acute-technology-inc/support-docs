    触发设置

    以下章节将介绍触发设置。您可依采集需求选择最适合的类型。 由于触发类型众多，我们将其分为不同章节以便查阅。

    Trigger Conditions

    这些是触发设置中各处可见的通用条件。 触发条件包括：

    • 0 - LOW 电平
    • 1 - HIGH 电平
    • X - 不关心（Don't care，允许任意值）
    • ↑ - 上升沿
    • ↓ - 下降沿
    • Either - 任意边沿（上升或下降沿）

    Trigger Types

    Single Level Trigger

    单次采集会持续录制数据，直到在单一通道上检测到数字触发为止。

    设置

    所有通道均可设置上述 触发条件。您可依采集需求选择最适合的条件。 最常见的用法是在时钟信号的上升沿触发。

    我们也支持从特定通道标签（例如 I2C）的特定二进制样式触发。

    • Trigger Delay（触发延迟）：触发前必须满足的时间间隔。默认为 0（立即触发）。
    • Pass Count（通过计数）：触发前要忽略的符合触发事件次数。默认为 0（第一次符合即触发）。

    Multi-level Trigger

    多级触发由多个单级触发条件组成。 您可以使用多个阶段（最多 16 个状态）建立复杂的触发条件。

    Warning

    采样频率 ≥ 2 GHz 时不支持 Multi-level Trigger（多级触发）。

    设置

    每个状态的设置方式与单级触发相同（如图右侧所示）。

    状态之间可以下列方式连接：

    Next IF

    连续触发条件（信号必须在相邻采样时钟上符合条件）

    • 相邻两个采样时钟所采集的信号都必须符合条件
    • 通常用于同步或状态模式测量
    • 信号处于连续、可预测的状态

    Then IF

    非连续触发条件（信号之间可间隔任意数量的采样点）

    • 两个条件都符合时即触发，中间的信号状态不影响结果
    • 适用于异步或时序模式
    • 适合边沿转换必须符合条件、但中间状态无关紧要的情境

    此外，您也可以加入 OR（OR IF）语句，建立并行条件。

    OR IF

    建立并行触发条件。任一符合的条件都会触发。

    Sequence by

    默认情况下，触发条件依内部采样时钟进行采样。 此功能可让您依自定义方式设置采样方法。

    示例

    若信号数据仅在时钟上升时有效，您可以：

    • 将 Sequence by 设为 Custom Rising
    • 选取 Clock 引脚作为有效条件
    • 使用多级触发为其他数据线设置条件

    Note

    Sequence by 功能仅在采样频率 ≤ 250 MHz 时支持。

    Width Trigger

    当通道符合触发条件且脉冲宽度符合指定长度时触发。

    Timeout Trigger

    当信号持续时间超过设定的时间值时触发，无需等待完整脉冲。

    External Trigger

    使用设备的 Trig-In 输入脉冲信号作为触发条件。

    Manual Trigger (Force Trigger)

    采集过程中，点击 Stop（停止） 按钮，可手动在已采集数据中设置触发点。

    Protocol Trigger

    我们支持不同的协议触发框架，让分析仪更强大且易于定位错误（完整参考文档即将推出）。
