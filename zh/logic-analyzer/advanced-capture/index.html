    高级采集设置

    除了上一节介绍的基本采集设置外，我们也提供以下高级采集设置供您选择。详细说明如下：

    Asynchronous Mode / Synchronous Mode

    Asynchronous Mode (Timing Analysis)

    异步模式（Asynchronous Mode）使用设备内部时钟作为采样时钟。此模式在大多数情况下为默认模式。它会以固定时钟速率持续采样，并要求信号经过过采样（oversampling）才能取得准确的时序。

    Tip

    一般建议采样率至少为信号频率的 5 至 10 倍。采样率低于信号频率的 5 倍会造成信号失真。

    Compound Mode

    我们也支持复合时钟（compound clocks），将外部时钟与内部时钟结合形成新的采样时钟。

    支持两种模式：

    • Asynchronous Mode (Record When CK0 = 0)：仅在外部时钟为 LOW 时录制
    • Asynchronous Mode (Record When CK0 = 1)：仅在外部时钟为 HIGH 时录制

    示例： 当 SPI Chip Select (CS) 为 0 时采集信号：

    • 选择异步模式（CK0 = 0 时录制）
    • 限定条件会将采集筛选为仅在 CK0 符合条件时进行

    Synchronous Mode (State Analysis)

    与异步模式不同，同步模式（Synchronous Mode）使用外部输入时钟作为采样时钟。

    同步模式提供以下预设模式：

    • Synchronous Mode (Latch on CK0 Rising)：在外部时钟上升沿采样
    • Synchronous Mode (Latch on CK0 Falling)：在外部时钟下降沿采样
    • Synchronous Mode (Latch on CK0 Either)：在外部时钟上升或下降沿采样

    设置：

    • 信号线上的 CK0 通道为外部时钟输入
    • 外部时钟停止时，信号采集也会停止
    • 在设备与外部时钟之间建立同步运作

    Advanced Settings

    设置多组边沿条件以同时采样。

    运作方式：

    每组边沿条件包含两组限定条件（qualifier sets）。任一限定条件符合时即立即采样。

    条件示例：

    • CK0 ↑ → 立即采样
    • CK0 ↑ + CK1 = 0 → 立即采样

    Glitch Filter

    我们提供毛刺滤波器（Glitch Filter）功能，用于抑制录制数据中的短脉冲，并消除这些短脉冲造成的错误逻辑状态。这是录制过程中常见的问题，因为我们无法保证环境中不会引入噪声。

    Tip

    使用示波器分析信号质量。尽可能消除噪声以取得更好的结果。

    Hardware Glitch Filter

    此功能在开始采集前应用低通滤波。滤波由硬件完成，因此数据采集完成后无法禁用。

    滤波范围：5ns 至 35ns

    使用硬件毛刺滤波器的通道会在通道标签上以 红点 标示，方便识别。

    Software Glitch Filter

    采集完成后滤除信号，不影响触发或时序。

    滤波范围：1ps 至 1ms

    特性

    • 仅变更显示与解码内容
    • 不会 影响触发
    • 不会 影响可录制时间
    • 禁用滤波器可还原原始未滤波波形

    相较硬件滤波器的优点：

    • 更宽的滤波范围（1ps 至 1ms，相对硬件的 5ns 至 35ns）
    • 非破坏性：保留原始录制数据
    • 可切换 ENABLE 或 DISABLE 以比较滤波前后结果
