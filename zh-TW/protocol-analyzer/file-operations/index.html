    檔案操作

    管理協定擷取檔案、在分析儀模式之間轉換，以及設定系統偏好。

    基本檔案操作

    開啟檔案

    從磁碟載入先前儲存的協定擷取檔案。

    支援格式：

    • TravelLogic 檔（*.TLW）
    • Logger 檔（*.LOG）— 用於 Protocol Logger 擷取

    儲存

    以現有檔名將目前視窗儲存為檔案。

    另存新檔

    以新檔名儲存，並可選擇指定儲存範圍。

    範圍選項：

    • 完整擷取
    • 游標範圍（若已啟用 Show Waveforms）
    • 自訂列範圍

    全部儲存

    一次將所有開啟的 Protocol Analyzer 與 Logic Analyzer 視窗儲存為檔案。

    模式轉換

    新增 Protocol Analyzer

    開啟新的 Protocol Analyzer 視窗，同時擷取另一個協定或匯流排。

    新增 Logic Analyzer

    開啟新的 Logic Analyzer 視窗做訊號層級時序分析。

    轉換為 Logic Analyzer

    從 Protocol Analyzer 切換到 Logic Analyzer 模式，同時保留擷取的資料。

    需求：

    • 必須啟用 Show Waveforms
    • 轉換前必須已擷取資料／波形

    會轉移的內容：

    • 波形資料
    • 通道設定
    • 臨界值設定
    • 觸發位置

    轉換後：

    繼續使用 Logic Analyzer 功能：

    • 訊號層級時序量測
    • 進階觸發
    • 游標式分析
    • 額外的匯流排解碼

    整合功能

    堆疊示波器

    將示波器量測加入 Protocol Analyzer 擷取。

    需求：

    • 必須啟用 Show Waveforms
    • 點選 DSO 圖示前，先擷取含波形的協定資料
    • 必須已連接支援的示波器

    運作方式：

    1. 在 Protocol Analyzer 啟用 Show Waveforms
    2. 擷取資料
    3. 點選 DSO 圖示進入 Logic Analyzer 視窗
    4. 設定示波器堆疊連線
    5. 檢視協定解碼搭配類比波形

    深入了解：Logic Analyzer — 堆疊示波器

    顯示偏好

    語言

    選擇顯示語言：

    • 英文
    • 繁體中文
    • 簡體中文

    語言設定套用於所有選單、對話框與報告。

    選項（系統偏好）

    設定 Protocol Analyzer 的應用程式層級設定。

    顯示設定

    1. 預設標籤高度： 修改波形區的通道高度
    2. 工作目錄： 暫存檔與擷取資料的位置
    3. 波形顯示類型： 選擇波形邊緣之間顯示的內容：
    4. 時間值
    5. 邏輯值
    6. 不顯示
    7. 展開波形色彩： 為每個通道啟用不同顏色

    啟動與儲存行為

    1. 軟體啟動時載入上次環境： 啟動時還原先前設定（不含波形）
    2. 每次擷取後儲存波形： 自動儲存到工作目錄
    3. 重複擷取行為： 設定重複擷取期間的波形解碼顯示
    4. 顯示間隔：1／2／5 秒

    報告選項

    1. 在 LA 解碼報告中顯示列號： 在報告區左側顯示列號
    2. 報告資料顯示位元組數： 設定每個報告欄位顯示的位元組數（Protocol Analyzer 專用）
    3. 詳細報告位元組數： 限制詳細檢視中顯示的位元組數

    觸發與游標

    1. Trigger out 脈衝寬度（μs）： 從觸發點到擷取結束的預設長度
    2. 在游標位置顯示波形值提示： 顯示通道號與匯流排解碼名稱
    3. 在解碼／轉態報告中顯示游標位置： 在報告時間欄位顯示游標位置
    4. 在游標列顯示游標間隔時間： 顯示游標之間的時間間隔
    5. 報告區游標字型大小： 調整游標位置顯示的字型大小

    裝置行為

    1. 自動重新連線裝置： 裝置離線後重新插上時自動重新連線

    波形顯示

    1. 在波形顯示中顯示通道資訊： 顯示通道號
    2. 在波形顯示中顯示值資訊： 數位顯示 0/1，類比顯示電壓
    3. 在波形顯示中顯示觸發資訊： 顯示觸發設定值
    4. 在波形顯示中顯示通道活動： 彙總邊緣轉態
    5. 顯示波形時間刻度虛線： 加上垂直線以對齊波形與報告

    處理

    1. 使用多核心處理： 啟用多核心 CPU 以加快資料處理
    2. 顯示報告時間戳資訊： 選擇時間戳格式：
      • 時序資訊格式
      • 含日期時間的時序資訊（觸發點為 0s）
      • 取樣點數格式

    通道管理

    1. 啟用以滑鼠拖曳合併標籤： 將一個通道標籤拖到另一個上以合併
    2. Logic Analyzer 游標量測分頁數上限： 游標量測群組數（3–10）

    字型設定

    設定下列項目的字型類型與大小：

    • 波形區文字
    • 註記
    • 通道標籤

    匯出選項

    將報告儲存為文字檔

    將協定解碼報告匯出為 .TXT 或 .CSV 格式。

    儲存選項：

    1. 儲存範圍：
    2. 所有資料
    3. 指定列數
    4. 進階報告： 匯出時包含詳細資料
    5. 分開時間戳欄位： 將時間戳分為兩欄：
    6. 時間戳欄
    7. 持續時間欄
    8. 每欄最大儲存位元組數： 限制每個欄位的位元組數

    深入了解：視窗管理

    提示與最佳實務

    工作目錄

    選擇符合以下條件的工作目錄：

    • 大型擷取有足夠的可用空間
    • 讀寫效能佳（Logger 模式建議用 SSD）
    • 若儲存重要擷取結果，定期備份

    自動儲存

    啟用「每次擷取後儲存波形」可：

    • 避免因當機而遺失資料
    • 保留擷取歷史
    • 快速復原先前的擷取

    注意： 自動儲存的檔案可能很快累積。請定期清理工作目錄。

    模式轉換流程

    協定分析 → 訊號分析：

    1. 在 Protocol Analyzer 啟用 Show Waveforms 開始
    2. 擷取感興趣的協定流量
    3. 出現訊號層級問題時轉換為 Logic Analyzer
    4. 用 Logic Analyzer 工具做細部時序分析
