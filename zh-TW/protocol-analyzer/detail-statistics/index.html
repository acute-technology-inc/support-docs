    詳細與統計

    檢視詳細的協定資料，並分析流量統計。

    詳細視窗

    檢視資料量龐大的協定交易的完整細節。

    概覽

    許多協定含有大量數值資料，不適合在主報告視窗顯示。詳細視窗提供這些資料的展開檢視。

    開啟詳細檢視

    方式：

    1. 在主報告視窗點選一列
    2. 特別點選 Data 欄
    3. 完整資料顯示於詳細視窗

    顯示內容：

    • 完整資料酬載
    • 格式化顯示（hex、十進位、ASCII 等）
    • 完整封包結構
    • 正確格式化的多位元組資料
    • 主報告未顯示的溢位資料

    使用情境

    大量資料傳輸：

    • 256 位元組以上的 I2C EEPROM 讀取
    • SPI flash 頁面讀取
    • UART 資料串流
    • CAN 延伸訊框

    複雜的協定結構：

    • 巢狀協定資料
    • 多層解碼
    • 子協定細節
    • 酬載解讀

    資料驗證：

    • 確認資料完整傳輸
    • 檢查資料是否損毀
    • 驗證 checksum 或 CRC
    • 與預期值比對

    統計視窗

    分析協定流量的樣式與特性。

    概覽

    統計提供整個擷取範圍內協定行為的高階分析。不同協定依其特性提供不同的統計。

    存取統計

    方式：

    1. 點選 Window 選單
    2. 選擇 Statistics
    3. 統計視窗顯示協定專屬分析

    常見統計

    流量分析：

    • 交易總數
    • 每秒交易數
    • 讀取與寫入比例
    • 位址分布

    錯誤分析：

    • NACK 數量
    • Timeout 發生次數
    • CRC／checksum 錯誤
    • 協定違規

    時序統計：

    • 平均交易時間
    • 最大／最小時間
    • 閒置時間百分比
    • 匯流排使用率

    資料分析：

    • 資料率（位元組／秒）
    • 平均酬載大小
    • 資料分布樣式
    • 協定命令頻率

    使用統計

    找出問題

    高階問題辨識：

    • 異常的錯誤率
    • 效能瓶頸
    • 非預期的流量樣式
    • 協定違規

    範例流程：

    1. 開啟統計視窗
    2. 注意到某位址的 NACK 率偏高
    3. 用搜尋找出 NACK 交易
    4. 為有問題的交易加書籤
    5. 用詳細視窗調查

    Trace 選擇

    點選統計 trace：

    • 彙總所選 trace 類型的所有記錄
    • 顯示於統計清單視窗
    • 顯示該事件類型的詳細分項

    範例：

    • 點選「Address 0x50」統計 trace
    • 檢視所有往返 0x50 位址的交易
    • 分析該特定裝置的樣式

    協定專屬統計

    不同協定提供相關統計：

    I2C：

    • 位址使用分布
    • Clock stretching 發生次數
    • START/STOP 條件數量
    • 各位址的 ACK/NACK 比例

    SPI：

    • Chip select 觸發次數
    • 資料傳輸大小
    • 時脈頻率分布
    • CS 閒置時間

    UART：

    • 鮑率準確度
    • 同位錯誤
    • 訊框錯誤
    • Break 狀況

    CAN：

    • Message ID 分布
    • 錯誤訊框數量
    • 匯流排負載百分比
    • 重傳統計

    Hide Data 視窗

    篩選顯示，聚焦相關資料。

    概覽

    用 Hide Data 功能暫時將資料項目移出檢視，讓您更容易聚焦特定協定活動。

    隱藏資料

    方式：

    1. 開啟 Hide Data 視窗
    2. 選擇要隱藏的資料項目
    3. 套用篩選
    4. 報告顯示更新為只顯示未隱藏的項目

    可隱藏的項目：

    • 特定位址
    • 交易類型
    • 錯誤狀況
    • 特定協定（多協定擷取中）

    還原資料

    方式：

    1. 開啟 Hide Data 視窗
    2. 點選 Clear 按鈕
    3. 所有隱藏的資料重新出現在報告中

    重要： Hide Data 只是顯示篩選。隱藏的資料仍在擷取中，隨時可取消隱藏。

    使用情境

    聚焦分析：

    • 隱藏已知良好的流量以檢視錯誤
    • 隱藏初始化序列以聚焦運作階段
    • 隱藏大量位址以檢視低流量問題
    • 隱藏特定命令類型以分析其他

    範例流程：

    1. 擷取顯示 0x50 位址有大量流量
    2. 隱藏 0x50 位址的交易
    3. 其他位址變得可見
    4. 不受干擾地分析低流量裝置
    5. 清除隱藏篩選以重新檢視完整樣貌

    儲存報告

    匯出詳細報告以做文件與進一步分析。

    儲存為文字檔

    報告、詳細與統計視窗的內容皆可儲存。

    支援格式：

    • .TXT — 純文字格式
    • .CSV — 逗號分隔值（可匯入 Excel／試算表）

    儲存選項

    1. 儲存範圍：
    2. 整個擷取
    3. 僅選取的列

    4. 指定列範圍

    5. 進階報告：

    6. 啟用： 包含詳細視窗的詳細資料

    7. 停用： 僅主報告資料

    8. 時間戳選項：

    9. 合併： 時間戳與持續時間放在同一欄

    10. 分開： 時間戳與持續時間分為兩欄

    11. 位元組上限：

    12. 每欄最大儲存位元組數
    13. 避免匯出時欄寬過大

    匯出流程

    做文件：

    1. 分析擷取，為關鍵事件加書籤
    2. 隱藏無關資料
    3. 將可見資料匯出為 CSV
    4. 在試算表中開啟並排版
    5. 加入測試報告或文件

    分享：

    1. 擷取並分析資料
    2. 匯出為 CSV 或 TXT
    3. 與團隊成員分享檔案
    4. 收件者可匯入其工具進行分析

    提示與最佳實務

    詳細視窗

    • 分析期間保持詳細視窗開啟
    • 用它驗證主報告的解讀
    • 將詳細檢視與預期的協定格式比對
    • 檢查主報告是否有截斷

    統計

    • 深入細節前先檢閱統計
    • 用統計引導該仔細看哪裡
    • 匯出統計以做多次擷取的趨勢分析
    • 比較擷取之間的統計以發現變化

    Hide Data

    • 大方使用隱藏資料 — 它不會破壞資料
    • 嘗試不同的隱藏組合以觀察樣式
    • 最終匯出前一律清除隱藏篩選
    • 在分析註記中記錄隱藏了什麼

    儲存報告

    • 長時間分析期間定期匯出
    • 用有意義的檔名儲存（含日期、測試 ID）
    • 為求最大彈性可考慮 CSV 格式
    • 文件中同時附上摘要報告與詳細報告
